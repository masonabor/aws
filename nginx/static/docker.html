Docker: Основи та концепції

Професійний посібник з контейнеризації

Що таке Docker?

Docker — це відкрита платформа для розробки, доставки та запуску додатків. Вона дозволяє відокремити ваш додаток від інфраструктури, що забезпечує швидку доставку програмного забезпечення.

Образ (Image)

Це незмінний файл (шаблон), який містить вихідний код, бібліотеки, залежності та інші файли, необхідні для запуску додатка.

Контейнер (Container)

Це запущений екземпляр образу. Контейнери ізольовані один від одного та від хост-системи, але використовують спільне ядро ОС.

Архітектура Docker

Docker використовує клієнт-серверну архітектуру. Docker-клієнт спілкується з демоном (Docker daemon), який виконує важку роботу по збірці, запуску та розповсюдженню ваших контейнерів.

Основні команди

Нижче наведено перелік команд, які найчастіше використовуються в продакшні:

# Перегляд запущених контейнерів
docker ps

# Запуск контейнера у фоновому режимі
docker run -d --name my-app nginx

# Перегляд логів конкретного контейнера
docker logs -f my-app

# Зупинка всіх процесів
docker stop $(docker ps -q)

# Очищення системи від невикористаних ресурсів
docker system prune -a

Docker Compose

Інструмент для визначення та запуску багатоконтейнерних додатків. Ви використовуєте YAML-файл для налаштування сервісів вашого додатка.

version: '3.8'
services:
  web:
    build: .
    ports:
      - "5000:5000"
  redis:
    image: "redis:alpine"
